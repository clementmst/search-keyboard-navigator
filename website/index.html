Questions

Frequently asked questions

How do I navigate Google Search results with my keyboard?

Install the extension, open a supported Google.com search-results page, and press Arrow Down. Use Arrow Down and Arrow Up to move between recognized result titles.

How do I open a search result in a new tab?

Use Chrome's native new-tab shortcut after focusing a result. Ctrl+Enter worked in the tested Windows Chrome setup; the extension does not control link disposition, so behavior can vary by platform or browser configuration.

Does ArrowKey Search Navigator collect my searches?

No. The extension processes page information locally and does not store or transmit search queries, result content, destinations, or keyboard activity.

Which search pages are supported?

The current version supports compatible desktop result layouts at www.google.com/search. Regional Google domains, mobile layouts, and every rich result type are not guaranteed.

Does it work with screen readers?

Screen-reader compatibility has not yet been established. Unmodified arrow keys may conflict with assistive-technology browse commands.
