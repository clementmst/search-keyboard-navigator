Enable keyboard navigation?

To move among results, ArrowKey temporarily examines the current enabled search page address, visible result links and page structure, focus state, and briefly checks keyboard events only to recognize eligible Arrow or Escape commands on your device.

This same local processing applies to Google and any optional site you enable below. It does not record typed text or send your searches, page content, or keyboard activity anywhere. Your choice is stored only in Chrome on this device.

Optional sites

Enabling a site loads ArrowKey's packaged code across that site so it works after in-page navigation, but it moves focus only on supported search routes. Displayed results can include personalized YouTube results or private GitHub repositories already visible to you. Nothing is sent to us.
