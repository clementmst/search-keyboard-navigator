# Candidate Project Skills

This directory is a quarantine for proposed skills. A file here is not active authority and must not be invoked as a project skill merely because it exists.

## Candidate package requirements

- Purpose, trigger, inputs/outputs, and explicit non-goals.
- Allowed tools, paths, network/external effects, and approval boundaries.
- Source/provenance and license records for any borrowed material.
- Threat analysis for untrusted instructions/content.
- Eval cases and results under `evals/`, including forbidden-action tests.
- Failure behavior, audit output, rollback/removal, version, owner, and reviewer.

## Initial ideas (not yet candidates)

- Manifest permission and match-pattern diff auditor.
- Synthetic Google-result fixture classifier/auditor.
- Release-evidence and artifact-inventory assembler.
- Research-source freshness and completeness checker.

These ideas have no implementation or authority. Creating or promoting them requires a scoped task and applicable approval.
