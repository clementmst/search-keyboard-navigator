# Active Project Skills

No project-scoped skills are active.

Activation requires a narrow documented purpose, explicit non-goals, provenance, least-privilege tools, representative and adversarial evals, independent review, versioning, rollback/removal instructions, and the approvals required by `AUTONOMY_POLICY.md`.

An active skill cannot publish, expand permissions, add retention/transmission/analytics or other data behavior, communicate externally, or weaken gates unless the user has explicitly approved that exact authority. Promotion records must link the evaluated candidate, results, reviewer, decision, and date.
