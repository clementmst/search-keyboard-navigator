# Chrome Web Store submission materials

This folder contains clearly named, human-facing copies of assets used while completing the Chrome Web Store dashboard. Engineering sources and provenance records remain under `assets/store` and `store`.

Folder: `privacy-policy-public-page`

- `search-keyboard-navigator-privacy-policy-for-google-sites.md` — draft policy copy for the public Google Sites page; reconcile it with the exact package and current Store fields before publishing the update.

## Store icon — 128 x 128

Folder: `store-icon-128x128`

- `search-keyboard-navigator-store-icon-128x128.png` — upload this file when the dashboard asks for the 128 x 128 Store icon.

Do not upload `assets/store/icon-master.png` in that field. The master is a 1254 x 1254 source image intended for generating final sizes, not a dashboard-ready icon.
