# Chrome Web Store listing draft — version 0.2.1

## Summary

Navigate supported Google Search results and YouTube videos with your keyboard.

## Single purpose

Enable keyboard movement among recognized Google Search result links and YouTube video links.

## Description

ArrowKey Search Navigator helps you move through supported Google Search results and YouTube videos without reaching for the mouse.

- On Google Search and YouTube search, ↑ and ↓ move between recognized titles.
- On the YouTube homepage, ↑, ↓, ←, and → follow the responsive video grid.
- The selected title receives a clear outline and right-pointing marker.
- The full selected YouTube homepage card remains visible while the page scrolls.
- Tab, Shift+Tab, Enter, and Ctrl+Enter remain controlled by Chrome and the page.
- Google Search and YouTube access can each be turned off from the popup.

The extension stays inactive in search fields and controls that use arrow keys. YouTube access is optional and reversible. It has no analytics, telemetry, advertising, backend, remote code, or extension-originated network requests, and it does not store or transmit searches, page content, destinations, or keyboard activity.

Current limitations: compatible desktop layouts only; Google `www.google.com/search`, YouTube `/results`, and the YouTube `/` homepage only. Ads, Shorts, shelves, carousels, rich or ambiguous units, and unsupported layouts are excluded. Site markup can change. Navigation does not wrap, and arrow keys may conflict with screen-reader browse commands. Screen-reader compatibility has not been established.

ArrowKey is independent and is not affiliated with or endorsed by Google, YouTube, or Microsoft. Platform names describe compatibility only.
