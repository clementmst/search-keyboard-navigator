# Chrome Web Store listing draft — version 0.2.0

## Summary

Navigate supported Google, YouTube, and GitHub search results with ↑ and ↓—without tracking.

## Single purpose

Enable keyboard movement among recognized result links on supported search pages.

## Description

ArrowKey Search Navigator helps you move through search results without reaching for the mouse.

- ↑ and ↓ move between recognized results.
- Enter and Tab remain controlled by Chrome and the page.
- A clear outline and right-pointing marker show your position.
- Google Search works after the initial Enable action.
- YouTube video search and GitHub repository search can be enabled separately from the popup.

The extension stays inactive in search fields and controls that use arrow keys. Optional site access is reversible. It has no analytics, telemetry, advertising, backend, remote code, or extension-originated network requests, and it does not store or transmit searches, page content, private repository information, or keyboard activity.

Current limitations: compatible desktop layouts only; Google `www.google.com/search`, YouTube `/results`, and GitHub repository search only. Site markup can change. Navigation does not wrap, and arrow keys may conflict with screen-reader browse commands. Screen-reader compatibility has not been established.

ArrowKey is independent and is not affiliated with or endorsed by Google, YouTube, GitHub, or Microsoft. Platform names describe compatibility only.
